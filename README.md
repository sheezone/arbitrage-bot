# Арбитражный бот (киберспорт: CS2 / Dota2 / LoL, теннис)

Telegram-бот, который следит за коэффициентами матчей (киберспорт и теннис) у
разных букмекеров и присылает уведомление, когда находит вилку (arbitrage) —
ситуацию, когда ставка на все исходы у разных БК даёт гарантированную прибыль
независимо от результата.

В интерфейсе бота CS2/Dota2/LoL объединены в одну категорию «Киберспорт» —
внутри они всё равно учитываются отдельно (у каждой игры свой sportId/категория
у источников), но переключаются одной кнопкой.

Бот **не делает ставки сам** и не хранит логины/пароли от букмекерских контор —
только считает и уведомляет. Ставки вы делаете вручную по подсказке бота.

Учитываются только чистые исходы "победа/поражение" (2-way). Матчи, которые уже
идут (live), и форматы с возможной ничьей (Bo2-серии) сознательно исключены из
расчёта — см. «Источники коэффициентов» ниже.

## Источники коэффициентов

Бот одновременно опрашивает три независимых источника и сравнивает их между собой:

1. **[OddsPapi](https://oddspapi.io)** (`bot/providers/oddspapi.py`) — легальный
   платный/бесплатный agregator, отдаёт котировки сразу многих букмекеров (bet365,
   1xbet, 22bet, kalshi и т.д.) через официальный, документированный API.
2. **Fonbet** (`bot/providers/fonbet.py`) — найден неавторизованный публичный JSON
   эндпоинт (без CAPTCHA), обнаруженный наблюдением за сетевым трафиком сайта, а не
   через официальную документацию. Может измениться или исчезнуть без предупреждения.
3. **PARI** (`bot/providers/pari.py`) — тем же способом найденный эндпоинт.

   ⚠️ **Важно**: Fonbet и PARI, судя по всему, работают на одном и том же
   трейдинг-движке — на 14 живых CS2-матчах их коэффициенты и даже внутренние ID
   событий совпали побитово. Значит, вилки между именно Fonbet и PARI никогда не
   возникнет — они всегда будут показывать одно и то же. Оба источника всё равно
   оставлены в наборе: у каждого есть шанс реально разойтись с котировками из
   OddsPapi, и именно там стоит ждать настоящих вилок.

Общий для Fonbet/PARI парсинг — в `bot/providers/_line_platform.py`, там же
подробно описана схема их дампа. Не проверял **Winline** (похоже, коэффициенты
идут через WebSocket, недоступный для используемых инструментов наблюдения) и
**BetBoom** (обнаружены признаки антибот-защиты, похожей на Group-IB fingerprinting
— обходить её не стал). **Лига Ставок** сейчас — то же юрлицо/бренд, что PARI.

## Сопоставление матчей между источниками

Так как Fonbet/PARI отдают только свои собственные котировки (в отличие от
OddsPapi, где один вызов уже даёт много букмекеров на одну фикстуру), нужен слой
сопоставления «это один и тот же реальный матч» — `bot/core/reconcile.py`.
Сопоставление идёт по нормализованному названию команд (без регистра/пунктуации,
в любом порядке) + времени начала с округлением до 30 минут.

**Известное ограничение**: сопоставление только по точному нормализованному имени,
без fuzzy-match. Если один источник называет команду сокращённо, а другой —
полностью, матч не склеится и просто не попадёт в сравнение (не ошибка, а
осознанный компромисс для MVP).

**Отдельное ограничение по теннису**: Fonbet/PARI отдают имена игроков кириллицей
("Джокович Н."), а OddsPapi — латиницей ("Djokovic N."). Без транслитерации это
никогда не совпадёт, поэтому реальных вилок по теннису между OddsPapi и Fonbet/PARI
сейчас не будет (а Fonbet↔PARI, как и в киберспорте, всегда идентичны). Теннис
всё равно включён в набор источников — но, по сути, ждёт транслитерации, чтобы
приносить пользу.

## Что нужно перед запуском

1. **Python 3.11+** (уже поставлен на этой машине через winget).
2. **Telegram Bot Token**: напишите @BotFather в Telegram, `/newbot`, следуйте
   инструкциям, скопируйте токен.
3. **API-ключ OddsPapi**: зарегистрируйтесь на https://oddspapi.io и возьмите ключ.
   Fonbet/PARI ключей не требуют — их эндпоинты полностью открыты.

## Установка

```bash
pip install -r requirements.txt
copy .env.example .env
```

Впишите в `.env`:
- `BOT_TOKEN` — токен от BotFather
- `ODDS_API_KEY` — ключ от OddsPapi

## Запуск

```bash
python -m bot.main
```

В Telegram напишите боту `/start`, дальше `/status`, `/bankroll`, `/threshold`,
`/games` — настройте под себя.

## Тесты

```bash
pytest
```

Покрывает математику арбитража (`bot/core/arbitrage.py`) и слой сопоставления
матчей (`bot/core/reconcile.py`) — оба без сети и токенов.

## Где что лежит

- `bot/core/arbitrage.py` — расчёт вилки и распределения ставок (чистые функции).
- `bot/core/reconcile.py` — сопоставление одного и того же матча между разными
  источниками.
- `bot/providers/base.py` — интерфейс `OddsProvider.fetch_quotes(games)`. Чтобы
  добавить ещё один источник, реализуйте этот интерфейс и подключите в
  `bot/main.py`.
- `bot/providers/oddspapi.py`, `fonbet.py`, `pari.py` — конкретные источники.
- `bot/core/monitor.py` — фоновый цикл: опрашивает все источники, сопоставляет
  матчи, считает вилки, шлёт уведомления, не дублирует одно и то же оповещение.
- `bot/handlers/commands.py` — команды Telegram-бота.
- `bot/db/` — sqlite-хранилище настроек пользователей и уже отправленных вилок.

## Известные ограничения / что стоит доделать при желании

- Fonbet/PARI дают только пары "команда 1 / команда 2" (2-way) — Bo2-форматы с
  возможной ничьей сознательно пропускаются (см. `_line_platform.py`).
- Скрапинг Fonbet/PARI идёт по недокументированным эндпоинтам — если бот вдруг
  перестанет находить вилки по этим букмекерам, вероятно, эндпоинт изменился;
  нужно заново посмотреть сетевой трафик сайта.
- Winline и BetBoom не подключены (см. «Источники коэффициентов» выше).
- Каждый цикл Fonbet/PARI скачивают полный дамп линии (~7 МБ) — поэтому
  `POLL_INTERVAL_SECONDS` стоит держать не меньше 120-150 секунд, чтобы не
  дёргать их инфраструктуру слишком часто.

## Важно про легальность и риски

Арбитражные ставки сами по себе не запрещены законом, но большинство
букмекерских контор запрещают их в своих правилах (ToS) и могут ограничивать
(лимитировать) или закрывать аккаунты, если заметят такую активность. Доступ к
Fonbet/PARI в этом проекте идёт через недокументированные, самостоятельно
найденные эндпоинты (не через официальный API) — это менее стабильно и более
хрупко, чем OddsPapi, и тоже может противоречить пользовательскому соглашению
этих букмекеров. Это инструмент для расчётов и уведомлений, а не гарантия того,
что каждая ставка будет принята БК без ограничений.

## Постоянная работа бота

Для непрерывного мониторинга бот должен работать 24/7 — обычный домашний ПК,
который выключается/уходит в сон, для этого не подходит. Стоит запускать его
на сервере/VPS (или хотя бы на ПК, который не выключается).
